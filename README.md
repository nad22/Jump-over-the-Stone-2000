# Jump over the Stone 2000 (Hüpf über den Stein 2000)

A silly Game Boy (classic, monochrome) game made with [GB Studio](https://www.gbstudio.dev/) 4.x.

- Title screen – press START
- One platformer screen with an animated hero and a stone in the middle
- Jump over the stone and land on the other side → "THE END" → extremely fast 90s-style credits
- **A** = jump, **B** = fart (with a rising little cloud)

## Play

Download `Huepf_ueber_den_Stein_2000.gb` from the [Releases](../../releases) page and run it in any Game Boy emulator or on a flash cartridge.

## Build

Open `Hüpf über den Stein 2000.gbsproj` in GB Studio 4.3 and choose *Build → Export ROM*.
